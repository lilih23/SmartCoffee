Comandos Git

Git Init

 
        git init - Inicializa repositório e mantem um histórico

Git Status


        git status - podemos visualizar o funcionamento correto do
        repositório

Git Add


        git add - Para preparar os arquivos da pasta
        git add nome_pasta ou arquivo
        git add .

Git Commit


        git commit - Irá enviar uma mensagem de confirmação para o GitHub
        git commit -m "mensagem que desejo"

Git Log


        git log - Irá exibir o histórico de commits 
        git log -- oneline - Irá exitir o histórico de commits resumido

Git Branch


        git branch - Irá exibir as branches existentes
        git branch nome_da_branch - Irá criar uma nova branch
        git checkout nome_da_branch - Irá alternar para a branch
        especificada

Git Remote


        git remote - Irá exibir os remotos configurados
        git remore add origin url - Irá adicionar um novo remote
        git push origin main - Irá enviar alterações para o remote
        git remote add origin link_repositorio
        git remote -v - Irá mostrar a URL configurada do origin

Git Push


        git origin main -Irá enviar alterações para remote 
        git push -u origin main - Irá enviar alterações para o remote e 
        definir a branch atual como upstream
        git push - Enviar atualizações para remote
